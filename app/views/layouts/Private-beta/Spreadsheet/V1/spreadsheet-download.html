Download Receipt of waste spreadsheet

If you do not have the software needed to use the API, you can send your data using Defra’s receipt of waste template spreadsheet.

You will need to:

  1. Download the spreadsheet template (XLSX, 441KB).
  2. Complete the mandatory data fields.
  3. Upload the completed spreadsheet.

Read our spreadsheet guidance for further help.

{% from "govuk/components/inset-text/macro.njk" import govukInsetText %} {% call govukInsetText() %} You cannot use your own spreadsheet or make format changes to Defra’s version. {% endcall %}

You can add multiple movements to the same spreadsheet before you submit it. After you submit it, you will need to use a new spreadsheet for your next submission.

If your organisation operates more than one site, you can also add those movements to the same spreadsheet.

If you operate multiple organisations, you will need to download a separate spreadsheet for each one.

View example spreadsheet

You can use our example spreadsheet to help you submit your own data. It shows what information you will need and how each section should be completed.

Download example spreadsheet (XLSX, 264KB).
