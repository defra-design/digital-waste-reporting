Receipt of waste spreadsheet: guidance

You need to complete 2 sections in the spreadsheet:

  1. Waste movement details
  2. Waste item details

Some of the fields you need to complete are self-explanatory (for example, site address and postcode).

In the fields that may need more explanation, we’ve added examples or additional context to help you.

Waste movement details

Errors found in your waste movements

This column will tell you if we have found any errors in your waste movement.

You will only be able to view these if there have been any issues found when you upload your waste movement spreadsheet.

Waste Tracking ID

This column will be populated after submission, and will tell you your Waste Tracking ID

Your unique reference

This is a reference for your waste movement. You will need this to link the waste movement to the associated waste item(s).

After uploading this will be replaced with a Waste Tracking ID, which you can provide to your customers.

Receiver’s authorisation number

A permit or exemption number that allows a site to accept waste for recovery or disposal.

For example, EPR/AB1234CD/A001

Regulatory position statements (RPS)

Statements that confirm what activities you do not require a permit for.

You can add multiple RPS codes. They must be separated by a semi colon ( ; ).

Guidance on Regulatory position statements (opens in new tab)

Date and time received

The date and time must be in the London/Europe timezone and in the format: dd/mm/yyyy hh:mm:ss.

For example, 01/01/2026 09:30:00

Hazardous waste consignment code

For example, HWCN/2026/004582

Special handling requirement

Handling instructions for waste that has the potential to cause harm.

Carrier registration number

Required for all businesses and organisations that transport, buy, sell or dispose of waste.

For example, CBDU345678

Carrier address

The full business location address of the carrier.

Carrier post code

The business location post code of the carrier.

Carrier contact email address

The email address of the carrier.

Carrier contact phone number

The waste carrier business contact number.

Means of transport

For example, road, rail, air or sea.

Broker or dealer registration number

For example, CBDU000000

Waste item level

Errors found in your Waste movements

This column will tell you if we have found any Errors in your waste movement.

You will only be able to view these if there have been any issues found when you upload your waste movement spreadsheet.

Your unique reference

For example, a weighbridge ticket number or waste transfer note number.

EWC code

A 6-digit code that classifies and describes the waste.

You can add multiple EWC codes. They must be separated by a semi colon (;). If you enter only one EWC code, please ensure that Excel does not format the code as a date by prefixing the code with a single quote (‘). No spaces should be added when entering EWC codes.

For example, 180103

Waste description

A detailed description of the waste, including physical characteristics, composition and if it’s potentially hazardous.

For example, Infectious healthcare waste such as sharps, contaminated dressings, swabs, and disposable medical equipment from hospitals, GP surgeries, or laboratories.

Physical form

For example, gas, liquid, solid, powder, sludge or mixed.

Type of containers

For example,
[BAG] Bag / Sack (for example rubble bag, refuse sack)
[PAL] Pallet (for example, shrink‑wrapped items).

Weight unit of measurement

For example, kilograms, grams or tonnes

Does the waste contain persistent organic pollutants (POPs)?

POPs are poisonous chemical substances that break down slowly and get into food chains.

POP name & concentration value

For example, Aldrin, Chlordane or Dieldrin.

Concentration is recorded as mg per kg, please only enter the numeric value.

Enter a POP code and concentration value by separating with an equals sign (=).

You can add multiple POP codes into each individual cell. They must be separated by a semi colon (;).

For example, ALD = 50; PCDD_PCDF = 25

How did you determine the POPs components?

Tell us how you determined the hazardous components, examples could be "Provided with the waste", or "Guidance".

If you were not provided with any documentation or relevant guidance, you can submit "Not Provided"

For example, OWN_TESTING or GUIDANCE

Is the waste hazardous?

Hazardous waste is any waste that is potentially harmful to human health or the environment.

Hazardous property codes (Haz code)

A code used to classify hazardous waste, for example HP_1 (Explosive waste) or HP_2 (Oxidising waste).

If you have multiple Haz codes, separate them by a semi colon (;).

For example, HP_1 ; HP_3

Waste classification technical guidance - GOV.UK (opens in new tab)

Component name & concentration value

Concentration is recorded as mg per kg, please only enter the numeric value.

Enter a component name and concentration value by separating with an equals sign (=).

If you have multiple components & concentrations, separate them by a semi colon (;).

For example, Cadmium = 50; Trichloroethylene = 25

How did you determine the Hazardous components?

Tell us how you determined the hazardous components, examples could be "Provided with the waste", or "Guidance".

If you were not provided with any documentation or relevant guidance, you can submit "Not Provided"

For example, PROVIDED_WITH_WASTE

Disposal / Recovery code & Weight

A code that determines the most appropriate treatment and recovery option for your waste. For each EWC code there must be at least one D or R code.

Choose a D/R code, weight/quantity for each code, unit of measurement and an estimate. You can do this by seperating with an equals sign (=).

You can add multiple Disposal or Recovery codes. They must be separated by a semi colon (;).

For example,
R2 = 400 = Kilograms = Actual
R5 = 130 = Kilograms = Actual; R12 = 130 = Kilograms = Actual
